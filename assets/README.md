# App icon placement

- Put your Windows icon file here as `counselog.ico`.
- Build script (`scripts/build_setup_windows.bat`) will auto-detect it and apply to PyInstaller EXE icon.
- Inno Setup (`installer/counsel_setup.iss`) will also use it as setup wizard icon when present.

Recommended: multi-size ICO (16, 32, 48, 64, 128, 256).
